Utilities#

Functions that are used in exhaustive and non-exhaustive template matching or are specific to template matching in general are grouped in the utilities module.

Subsetting#

split_shape(shape, splits[, equal_shape])

Splits shape into equally sized and potentially overlapping subsets.

center_slice(current_shape, new_shape)

Extract the center slice of current_shape to retrieve new_shape.

apply_convolution_mode(arr, ...[, ...])

Applies convolution_mode to arr.

Utilities#

standardize(template, mask, n_observations)

Standardizes template to zero mean and unit standard deviation in mask.

create_mask(mask_type[, soft_edge_width, ...])

Creates a mask of the specified type.

scramble_phases(arr[, seed])

Perform phase scrambling of arr.

array_to_memmap(arr[, filename, mode])

Converts a obj:numpy.ndarray to a obj:numpy.memmap.

memmap_to_array(arr)

Convert a obj:numpy.memmap to a obj:numpy.ndarray and delete the memmap.

conditional_execute(func[, ...])

Return the given function or alternative function based on execute_operation.

minimum_enclosing_box(coordinates, **kwargs)

Computes the minimal enclosing box around coordinates.

generate_tempfile_name([suffix, tmpdir])

Returns the path to a temporary file with given suffix.

Rotations#

align_to_axis(coordinates[, weights, axis, ...])

Calculate a rotation matrix that aligns the principal axis of a point cloud with a specified coordinate axis.

align_vectors(base[, target])

Compute the rotation matrix or Euler angles required to align an initial vector with a target vector.

euler_to_rotationmatrix(angles[, seq])

Convert Euler angles to a rotation matrix.

euler_from_rotationmatrix(rotation_matrix[, seq])

Convert a rotation matrix to Euler angles.

get_cone_rotations(cone_angle, cone_sampling)

Generate rotations describing the possible placements of a vector in a cone.

get_rotation_matrices(angular_sampling[, ...])

Returns rotation matrices with desired angular_sampling rate.

Masks#

box_mask(shape, center, size, **kwargs)

Creates a box mask centered around the provided center point.

tube_mask(shape, symmetry_axis, center, ...)

Creates a tube mask.

elliptical_mask(shape, radius[, center, ...])

Creates an ellipsoidal mask.

membrane_mask(shape, radius, thickness, ...)

Creates a membrane mask consisting of two parallel disks with Gaussian leaflet intensity profiles.
